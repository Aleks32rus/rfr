# UI-тесты

Тест `RegistrationTest` создаёт уникального пользователя через интерфейс, проверяет сообщение об успешной регистрации, входит с теми же данными и проверяет карту путешествий и логин в профиле. Локаторы, переходы и проверки страниц находятся в Page Object-классах пакета `io.student.rangiffler.page`. Шаги размечены для Allure.

Для запуска нужны MySQL, сервер авторизации на порту 9001, API на порту 8081 и клиент на порту 3001. Подготовка приложения описана в корневом README. Также требуется браузер Chromium для установленной версии Playwright Java.

Запуск из корня проекта в PowerShell:

```powershell
.\gradlew.bat :rfr-e2e:test --tests io.student.rangiffler.test.RegistrationTest
```

Для другого адреса клиента установи переменную окружения `RFR_FRONT_URL`. Класс теста использует `@UsePlaywright`: расширение JUnit передаёт `Page` в тестовый метод, создаёт отдельный контекст для каждого теста и закрывает его после выполнения, в том числе при ошибке. Жизненным циклом браузера и Playwright также управляет расширение. Каждый запуск использует уникальные логин и пароль. Созданный пользователь остаётся в тестовой БД.

HTML-отчёт Gradle: `rfr-e2e/build/reports/tests/test/index.html`.

## Проверка сценария через Playwright MCP

Сценарий и локаторы проверены в работающем приложении через Playwright MCP: ссылка `Register`, форма регистрации, сообщение `Congratulations! You've registered!`, переход `Sign in` → `Login`, форма входа, карта и профиль. Для имени пользователя используется роль `textbox` с точным именем `Username`; для паролей — уникальные подсказки полей. Ссылка `Profile` ограничена областью `banner`, поскольку в меню есть вторая ссылка с тем же именем.

При исследовании обнаружена сохранённая сессия сервера авторизации: кнопка `Login` могла сразу открыть кабинет другого пользователя. После выхода через интерфейс выполнен вход с данными нового аккаунта; в профиле подтверждён его логин. Поэтому автотест использует новый контекст браузера, проверяет заголовок формы входа и завершает сценарий проверкой логина созданного пользователя.
