# rfr-auth

- Изменение способа хранения ключей подписи требует отдельного решения; постоянные ключи не добавляй в репозиторий.
- Аутентификацию публичного клиента через `client_id` на revocation endpoint не распространяй на другие операции без проверки требований протокола.
- Не создавай профиль API прямой записью из auth в чужую БД.
- При изменении полей и доступных имён в шаблонах согласованно обновляй E2E Page Object.
